# Overview of databases

Many commonly used data sources are stored locally at UPPMAX. This page provides an index to pages where they are described in more detail.
Available databases:

- [BLAST databases available locally](blast.md)
- [NCBI taxonomy databases](ncbi.md)
- [DIAMOND protein alignment databases](diamond.md)
- [Reference genomes](reference_genomes.md)
- [1000-genome project](1000-genome_project.md)
- [Simons Genome Diversity Project datasets](simons_genome.md)
- [Other bioinformatics-oriented local data resources](other_local.md)

In order for you to access **Swegen** or **1000-genomes** request membership
in the "KGP" group (via `support@uppmax.uu.se`).
