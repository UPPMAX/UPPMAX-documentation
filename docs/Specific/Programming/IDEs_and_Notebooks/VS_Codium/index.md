# VSCodium

VSCodium is the community edition of [Visual Studio Code](../VS_Code/index.md)
and is an [IDE](../ides.md) that can be used for software development in many languages.

![VSCodium running on Bianca](../../../../software/img/vscodium_on_bianca_480_x_270.png)

> VSCodium running on Bianca

If you can use VSCodium, depends on the HPC cluster:

Cluster                                 | Works/fails |Documentation page
----------------------------------------|-------------|---------------------------------------------------------------
[Bianca](../../../../cluster_guides/bianca.md)   | Works       |[VSCodium on Bianca](vscodium_on_bianca.md)
[Pelle](../../../../cluster_guides/pelle.md) | Fails [^1]   |None

[^1]: Use [VSCode on Pelle](../VS_Code/vscode_on_pelle.md) instead
