---
title: IDEs and Notebooks
---

There is essentially three different groups of tools for programming:

### IDEs

Integrated Development Environments, applications that gather all the
tools for working with the code, often modular or at least extensible.

Some text editors are so extensible that they become IDEs in practice.
For this documentation, we categorize VS Code as an IDE and Emacs as a text editor.
Opinions and usecases will vary.

### Separate tools

Text editor, compiler/runtime, debugger, version control et.c. as separate tools.

### Programming notebooks

Puts the code and its output in a unified document.
An extension of literate programming that often applies well to research code.
