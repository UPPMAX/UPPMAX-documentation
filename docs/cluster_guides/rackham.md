# Rackham

![Red Rackham, from https://tintin.fandom.com/wiki/Red_Rackham](./img/red_rackham_103_x_238.jpg)

Rackham was one of the [UPPMAX clusters](uppmax_cluster.md)
that is a general-purpose cluster.

Rackham was completely replaced by [Pelle](pelle.md) at 2026-01-30.
